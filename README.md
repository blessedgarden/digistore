# DigiStore

Интернет-магазин для продажи цифрового контента (программы, лицензионные ключи, электронные книги, медиа-контент). После успешной оплаты покупателю автоматически выдаётся уникальный цифровой ключ из пула, привязанного к товару.

Курсовой проект по дисциплине МДК.09.01 «Проектирование и разработка веб-приложений».

## Стек

- **Backend:** PHP 8.2+, Laravel 12, Eloquent ORM
- **Frontend:** Blade, Tailwind CSS 4, Vite, JavaScript (Axios)
- **БД:** MySQL
- **Окружение:** XAMPP / Apache

## Возможности

### Покупатель
- Каталог с фильтрами, сортировкой и поиском по товарам.
- Карточка товара с описанием, ценой, отзывами и индикатором наличия ключей.
- Корзина с применением промокодов.
- Регистрация, авторизация, личный кабинет.
- Оформление заказа и автоматическая выдача цифрового ключа после оплаты.
- История заказов и повторный просмотр выданных ключей.
- Отзывы о купленных товарах с оценкой полезности.

### Администратор
- Дашборд со статистикой продаж.
- CRUD для товаров, категорий, пользователей, промокодов.
- Загрузка пула цифровых ключей для каждого товара.
- Управление статусами заказов.
- Модерация отзывов.
- Журнал действий администраторов (ActivityLog).

## Структура моделей

| Модель | Назначение |
|---|---|
| `User` | Пользователи (роли: user / admin) |
| `Category` | Категории товаров |
| `Product` | Товары |
| `DigitalKey` | Цифровые ключи (хранятся зашифрованно) |
| `Order` / `OrderItem` | Заказы и их позиции |
| `Promo` | Промокоды |
| `Review` / `ReviewHelpfulVote` | Отзывы и голоса полезности |
| `ActivityLog` | Журнал действий администраторов |

## Установка

```bash
git clone https://github.com/blessedgarden/digistore.git
cd digistore

composer install
npm install

cp .env.example .env
php artisan key:generate
```

Настройте подключение к БД в `.env` (`DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`), затем:

```bash
php artisan migrate --seed
npm run build
php artisan serve
```

Сайт будет доступен по адресу `http://127.0.0.1:8000`.

### Режим разработки

```bash
npm run dev          # Vite dev-сервер с HMR
php artisan serve    # в отдельном терминале
```

## Безопасность

- Пароли хранятся в виде bcrypt-хешей.
- CSRF-защита на всех POST-формах.
- Экранирование вывода в Blade (защита от XSS).
- Параметризованные запросы через Eloquent (защита от SQL-инъекций).
- Цифровые ключи шифруются через `Crypt` фасад Laravel.
- Разграничение доступа через middleware `auth` и `AdminMiddleware`.
